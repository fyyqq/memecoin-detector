# Memecoin Detector

A lightweight memecoin intelligence platform for detecting trending
memecoins, related-token movements, pump catalysts, and historical leaders.

## Stack

- React.js
- Laravel
- PostgreSQL
- Docker
- DBeaver
- Dexscreener API

## Core Sprint 1 Goal

Discover newly launched memecoins across supported chains with:

- Market cap >= $5M
- Age <= 30 days
- Current momentum
- Volume
- Liquidity
- Chain
- DEX
